# 分类和审核规则

用户已有目录先理解并保留合理结构。否则以下作为起点，只创建有实际素材的类别。

| 目录 | 画面判定 |
| --- | --- |
| 00_黄金开头_待测候选 | 人工精选，记录理由和基础用途，不保证表现 |
| 02_痛点与问题 | 可见肤质／使用困难，不猜疾病 |
| 03_产品展示 | 包装瓶身、开箱，图文说明单列 |
| 04_开盖取量与质地 | 开盖、挤出、倒出、按部位上料 |
| 05_核心使用演示 | 随产品细分；去角质可命名“搓泥演示” |
| 06_结果细节 | 泥屑、擦出物、质地；搓出物不等于已证明死皮 |
| 07_擦拭与冲洗 | 区分纸巾、毛巾、流水和部位 |
| 08_效果与前后对比 | 区分同屏／前后切换／单纯净肤；不代表已验证疗效 |
| 09_人物口播与反应 | 人物讲解、拿瓶介绍、反应；未听辨不推断台词 |
| 10_购买引导与促销 | 用户允许时保留价格和购买提示 |
| 11_其他辅助画面 | 动画、道具、情景、拼贴；夸张污渍单列非功效证据 |
| 12_复合段_需二剪 | 多部位、多用途、产品＋演示混剪未真正分开 |
| 13_单部位连续使用过程 | 同部位的上料→搓泥→擦拭连续过程，非纯单动作 |
| 90_其他产品与非本品主题 | 明确其他主题时隔离保留 |
| 99_待复核 | 主用途不明，不用推测填满类别 |

去角质部位候选：手背与手指、手臂、手肘、腋下、脖颈、背部、膝盖、腿部、脚背脚踝、脚跟脚底、腹部躯干、面部、待确认。眼霜可改眼周上料、按摩、皱纹／眼袋画面、质地等。

## 易错边界

- 手持瓶子的口播不是纯产品展示；三帧依次产品／皮肤／纸巾属于混合过程。
- 手指擦手肘以被处理部位为准，不按执行动作的手分成手背。
- 肤质近景未见前后关系不能叫前后对比；长段关键帧一致也可能漏掉中间插入。
- 原片夹带其他产品先定位具体段落，整片其他主题有充分证据才整片隔离。
- 黄金开头仅选已实际复核版本，不把同组所有近似版本都打精选标签。

## 审核记录

`review_method`：full_playback / manual_keyframes / grouped_unreviewed / unresolved。
附 `review_notes`、`needs_recut`、`body_part_uncertain`、`hook_candidate`、`hook_reason`、`base_category`。

关键帧审核记录实际时间点，不转述为逐帧审核。组员未单独查看必须标 grouped_unreviewed。仅关键帧审核素材在正式批量剪辑入选后再看实际片段。

迁移至少记录编号、旧新路径、旧新分类、原因，保留历史审核依据。断点恢复依据已验证文件和清单，不只看目录存在。
