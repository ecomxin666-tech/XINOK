# 产品广告分镜素材库 Skill

名称：`product-ad-shot-library`。适用于去角质、美白凝胶、眼霜等产品成片的拆镜头、用途／部位分类、待复核素材整理及开头候选筛选。

## 给其他人安装

解压 ZIP，把里面整个 `product-ad-shot-library` 文件夹放进对方的 Codex 技能目录：默认是用户目录下的 `.codex/skills/`；设置过 `CODEX_HOME` 则放在该目录的 `skills/` 下。不要只复制 SKILL.md，不要多套一层同名目录。重新打开 Codex 或新建会话后使用。

也可以将 ZIP 和这段要求发给对方的 Codex：“请检查这个技能包，安装到我的 Codex 技能目录，不覆盖已有同名技能；有冲突先告知我。”

## 调用示例

```text
使用 $product-ad-shot-library
素材原片：/你的原片目录
输出目录：/你的分镜目录
产品：去角质凝胶
卖点：搓泥、肤质展示、使用过程、擦拭反差
细化部位：手背、手臂、手肘、腋下、脖颈、膝盖、腿部、脚部、面部
保留原字幕、价格和原声音轨，不按固定秒数均分。
根据完整动作拆解；混合段单独标需二剪；挑选黄金开头待测候选。
先处理少量多样样本给我确认，再批量执行。
```

已有素材库可这样说：“使用这个技能，复核我素材库里的待复核目录，保存旧清单，仅整理分类，不重新编码；混合段标需二剪。”

## 依赖与边界

- 本地 Python 3、ffmpeg；联系表需要 Pillow，ffprobe 推荐但非必需。由执行环境确认依赖，不会自动安装。
- 语义分类需要支持查看图像／视频的 Codex 环境；脚本本身不识别产品或身体部位。
- skill 是指导代理工作的规则和技术助手，不是双击即完成的无人值守软件，不附带付费 API、后台服务或广告账户权限。
- 不保证 CTR，也不保证每段已经人工完整观看；审核依据必须如实记录。
- 包内不含真实素材、客户清单、私人路径或密钥。不附带第三方技能源码，独立使用，无需安装本次对话里的其他技能。

已完成验证：技能结构校验；合成视频的切点候选检测、六帧联系表、带音轨裁剪、完整解码、时长检查，以及拒绝覆盖已有输出。大规模真实素材处理仍需样本校准与人工复核。
