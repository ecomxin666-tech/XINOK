# 产品广告分镜素材库

目标：建立可追溯、分类与画面相符、便于批量剪辑的素材库。适配去角质、美白凝胶、眼霜等产品，不把去角质分类强套到所有产品。

## 开始前

确认素材路径、输出路径、产品及主要卖点、处理范围、已有分类是否沿用，以及品牌／价格／音轨保留要求。对话已有答案就执行，不重复确认。只有关键条件缺失才询问。整理已有素材库时优先迁移分类、保存旧清单，不重新编码或重复导出全部文件。

检查磁盘及依赖，不假设存在本机专用路径或 API。附带工具需要 Python 3、ffmpeg，推荐 ffprobe；联系表另需 Pillow。可复用环境已有等效工具。没有视觉查看能力时停止语义分类，仅交付技术结果并说明限制。默认不上传视频、不调用付费接口；需要时先取得授权。

阅读 [分类和审核规则](references/classification.md)。使用附带工具时再读 [本地工具与清单格式](references/tools.md)。

## 拆解与视觉判断

1. 递归列出视频，排除系统隐藏文件；按用户日期／目录范围筛选，输出实际清单。日期有歧义先解析展示范围，不靠字符串排序猜日期。缓存按内容或文件状态识别变化，未变化素材不重复分析。
2. 场景检测只生成候选边界，不直接当成最终镜头。先以少量多样素材校准，随后分批生成起、中、尾联系表，保留源片与时间戳供回看。
3. 根据看见的画面判断用途和部位。首中尾不一致、长段、混合动作、产品展示、黄金开头或证据不足时，增加采样或播放原段。抽帧可能漏掉插入镜头，不声称完整观看。
4. 按自然镜头和完整动作裁剪，默认不限 5 秒或 10 秒，不均分。修正漏切与误切，动作中间的碎片优先合并。语音连续性影响取材时另做转写或听辨，视觉切点不等于句子边界。
5. 仅整理分类时保留原边界；多用途段进入“复合段_需二剪”，不能只改文件夹名字就宣称拆干净。重新切段时记录新旧关系并验证覆盖与重叠。
6. 逐条记录审核依据：完整播放、人工多关键帧、相似组匹配未单独复核、未确认。相似度只帮助分组和去重，不能替代语义判断；组员不能继承代表图的人工复核状态。

## 分类与黄金开头

单片段仅保留一处主文件；部位、动作阶段、原片开头位置及候选理由保留在清单，不为标签复制视频。产品展示要求主体确实是产品；人物拿瓶讲解、上料演示和产品＋演示拼接分别归类。部位不明时记录明确动作，部位待确认，不猜。

黄金开头放 `00_黄金开头_待测候选`：选择明显搓泥变化、动作直入、痛点特写、擦拭揭晓或清晰反差。重点回看连续画面，剔除近似重复；不因位于原片前几秒就入选。不预测 CTR，不把夸张污渍、肤色深浅、灯光变化或动画当真实功效证据。广告表现需实际投放测试。

## 导出、复核与交付

- 原片只读。迁移分类前保存旧清单及旧→新路径映射，不覆盖同名目标；先验证计划再执行。默认保留字幕、价格和音轨，除非用户另有要求；烧录文字不能无损移除。
- 新片段准确解码裁剪，避免流复制导致关键帧漂移。保留画幅和可用音轨，验证起止、时长、可解码性、存在与大小；技术检查和视觉准确性分别统计。
- 仅在获得明确删除授权后删除文件。相同字节可提出去重方案；相似画面、不同字幕或音轨不能静默当作完整重复删除。
- 交付主清单、源片覆盖清单、技术校验、分类变更表（整理任务）、规则和总结。至少记录来源、起止、时长、分类、部位、审核依据、目标路径及缺漏／失败项。
- 自动取材默认排除待复核、部位待确认、其他产品、未单独复核组员和复合段；连续使用过程按需二剪。原有未复核类别不因本轮整理自动升级。
- 汇报源片成功／失败、片段数、候选数、复合段、连续过程、其他主题、未确认和审核覆盖。明确哪些只是归类、哪些重新裁剪。待复核目录变空不代表全都已确认。

批量处理采用可恢复清单、分批检查。没有终审不得报告全部完成。此 skill 不自行创建后台任务、不发布内容、不修改广告账户。
