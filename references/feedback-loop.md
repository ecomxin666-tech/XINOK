# TikTok 数据回传闭环

## 内容编号

每条成片使用稳定编号，例如：`BR-EXF-20260923-A01`。同一个编号必须同时写入：

- 剪映草稿名或备注。
- 剪辑计划/分镜清单。
- 发布台账。
- 回传的成片文件名。

## 建议回传字段

| 类别 | 字段 |
|---|---|
| 身份 | 内容编号、草稿名、账号、地区、发布时间、是否投流 |
| 播放 | 播放量、2 秒留存、6 秒留存、平均观看时长、完播率 |
| 互动 | 点赞、评论、分享、收藏、关注增长 |
| 转化 | 商品点击、CTR、下单量、CVR、GMV、投流消耗 |
| 实验 | 钩子类型、产品首次出现时间、替换比例、CTA 类型、唯一测试变量 |

建议至少记录发布后 24 小时、72 小时和 7 天三个快照。比较时区分自然流量与付费流量，并尽量在相同账号、受众和发布时间段内对比。

## 分析原则

- 2 秒留存低：优先检查首帧、第一句话和前 1–2 秒动作强度。
- 6 秒留存低：检查钩子是否兑现、镜头是否与口播匹配。
- 平均观看和完播低：压缩重复证明镜头，增加 3–5 秒一次的视觉变化。
- 点击低但观看高：强化产品露出和 CTA。
- 点击高但下单低：先检查商品页、价格、促销和受众，不要把问题全部归因于剪辑。
- 用至少多条相近条件的视频验证规律，再将其写入长期剪辑标准。

## 长期文件

建议维护：

- `剪辑标准.md`：稳定规则。
- `视频实验台账.xlsx`：每条视频与多时间点数据。
- `优化结论.md`：已被多条视频验证的结论、证据和适用范围。
